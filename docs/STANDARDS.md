# 制作标准 / Standards
整理自 2026-10-31 至 2026-11-14 的全部对话。后出现的要求覆盖先前的要求。

## 1. 总原则
- 一切以「真实、逼真、可考据」为第一标准；能查史料就查，推演要符合现实逻辑。
- 复刻类工作一律**像素级复刻**，反复与原始截图比对整体 UI，包括滚动条、字体、图标、间距。
- 慢慢做、质量优先、尽量节省额度（2026-11-08 起反复强调）。
- 阶段性进度可以截图给用户看；完成一轮后截图 + 发布网页 + 提供代码下载。用户说「先不发布」时不发布。
- 来源年代不必过分苛刻（用户 2026-11-01：「不用太苛刻」），但应尽量取 2009 年前后的真实素材。

## 2. 语言
- 所有政权名称、信息文字、UI 标签：中英双语，可切换（右上角拟物化谷歌齿轮）。
- 默认语言：中文；默认图层：夜景。
- 以中文版为主要质量标准（2026-11-08）。
- 例外：谷歌首页按英文截图像素比对，不再区分中英（公告除外）；「Radio Silence」大字只用英文。

## 3. 地图本体
- 范围：仅北美。三层：势力/国界实心填色、逼真夜间城市灯光（要逼真且不卡）、地形。
- 边界：不完全按行政区，部分按地形（山脊、河流、流域、沙漠），需按资料精细设计；放大后边界不能乱、不能有断开的碎点，州界不是势力线。
- 控制线（只有一条线连接的走廊）要复刻；线中间若有城镇，画较粗的点。
- 无势力区域：黑色「无线电静默」，填充为逼真的动态老式电视噪声；背景放超大、拉长、复古（Old Roman / 略带手写感、大小写混排）的 "Radio Silence" 英文字，以噪声填色并与背景噪声在形状上可区分。
- 位于噪声区的地名：略上下拉长、带伪影/RGB 错位的字体。
- 游击区（阿巴拉契亚等）：动态斜条纹，较细碎；势力交界争夺区也可加动态斜线。
- 墨西哥占领区：墨西哥国色淡化版，未完全占领处加斜条纹，附双语推演说明。
- 加拿大、墨西哥、中美洲、加勒比按现实状态。
- 所有「XX州」与泛联邦势力使用各不相同的蓝色。
- 国名显示算法：参考真实地图处理狭长、过小、分散区域，可沿曲线/竖排/非同一行排布；中英区分。
- 光标：全站使用 Windows 7 Aero 光标（含忙/后台运行动画），见 `site/cursors/`（2026-11-14）。
- 2009 液晶屏质感：TN + CCFL 背光 + 雾面涂层的整屏模拟，可在齿轮菜单切换（2026-11-14）。
- CRT 效果：按真实原理复刻 1990–2000 年 CRT（荫罩/栅格、RGB 荧光点、光晕、桶形曲率、暗角、会聚误差、余辉、玻璃反光），禁止假扫描线条纹，可开关可调强度，不能明显影响阅读。

## 4. 界面风格
- 整体从 80 年代 lo-fi 改为 **2000–2009 年谷歌地图风格**，像素级复刻，包括 2009 年浏览器内滚动条（不是 XP 蓝色滚动条）、字体、左上角 logo、真实图标。
- 去掉冗余可调信息。
- 左侧栏：2009 年谷歌地图本地搜索式列表（分页、更多信息/维基百科/放大链接）。
- 每个势力有谷歌地图气泡框，点击打开维基页；气泡里不放国旗（真实谷歌地图不会这样，国旗属于维基配图）。
- 鼠标悬停小框的国名必须与势力一致。
- 地图右边界有突出的灰白书签图标，点开 2009 风格网站列表；初始只开谷歌标签页。
- 浮动 Chrome 窗口：基于 7.css（需做好样式隔离，防止溢出），复刻 Chrome 标签页形状与毛玻璃结构；新标签页按钮为方向正确的平行四边形；需要假的刷新、后退功能；多窗口堆叠/焦点要正确。

## 5. 复刻网站（书签内）
通用：像素复刻当年 UI 与交互；可做「点击感」的假交互，但不要弹出新内容；复杂元素可直接从原图裁切。
- **Google 首页（2009–2012）**：特殊 banner = 真实 2009 logo + 老式 GIF 质感的火焰与斜向上浓烟（要逼真且不能卡顿）；搜索按钮正下方紧凑的淡黄色警告横幅（#ffe694/#ffffcc 类，系统默认字体）；「手气不错」必须能用。
- **网络拓扑图窗口**：2009 年斜三维/伪 3D 的 Cisco 与 Visio 3D 图标质感，不要廉价 SVG 感；蓝色渐变背景；简化地图、不分势力；基列站点红 X，无线电静默站点问号，连线由实线变虚线；动态立体防火墙、受攻击服务器着火动态图标；**不要图例、不要三维网格背景**。
- **CNN 2009 首页**：静态像素复刻，虚构灾难标题与配图，不出现真实受害者形象；滚动条正确。
- **YouTube 2009**：完全 2009 年 UI 与交互；yt2009 只取优于现有的部分（如原版贴图），不整体替换、不引入 Flash，注意许可证署名。
- **维基百科（2009 MonoBook）**：条目文案必须像真实维基——段落长短不一、不能每段等长、不能有 AI 感；可引用真实刊物与细节（人物本身除外）；时间线按《使女的故事》原著为主，续作、电影、剧版补充，可提前到 2009 年；可以虚构人物。
- **Craigslist**：真实的社区气息——宗教、大量普通帖子、危机（失踪等）并存，需详细推演，不能只有换发电机、找家人。
- **The Big Picture**：氛围感强的大图新闻摄影。
- **Flickr 2009**：以加州用户为主，也有沦陷区普通人在断网前拍的相册；照片体现 2009 年数码相机或 iPhone 拍摄、构图不完美、真实感、符合事实。

## 6. 图片
- 除国旗外，真实感照片尽量不由 Hark 自行生成；需要时列清单或提示词给用户。
- 2026-11-09 起：本项目的照片复刻图可直接用用户的 ChatGPT 生成，无需每次征得同意；可批量出图（实测每条消息一个提示词更稳）；提示词用自然语言，适中长度、列出要点，不要过长的英文。
- 图片要裁切、压缩到符合 2009 年网页的尺寸与压缩外观；照片角落的时间戳要正确，必要时从原图裁切。
- 用户提供的 AI 图片可直接使用，适当压缩。

## 7. 旗帜
- 先查是否有历史上真实存在的旗帜/州印（如 1851 德塞雷特旗、1905 塞阔亚州印），有则以其为原型。
- 流程：先做简陋矢量草图作参考 → 再生成干净、逼真、平铺、**不做旧**的电子版。不要做旧/实物照风格，也不要纯矢量的简陋感。
- 信息面板标注双语出处，例如「原型：1851 年德塞雷特国旗 / Based on the 1851 Deseret national flag」，按原比例不裁切。

## 8. 设定
- 虚构州由原法定州民众在不同时期建立：富兰克林州、德塞雷特州、塞阔亚州为早期分歧（很早就正常建立）；其余多为灾难后自发建立。设定须有历史渊源。
- 联邦政府首都：萨克拉门托。
- 新英格兰剩余地区全归基列；几个王国/分区不合并，名称去掉「基列」二字，颜色不变。
- 波士顿—华盛顿之间连成基列领土；基列首都连接波士顿。
