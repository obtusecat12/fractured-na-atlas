# 莫诺卡西病 / Monocacy disease（设定草案）

**莫诺卡西病**（Monocacy disease），医学文献又称**格状麻风**（拉丁语 *Lepra cancellata*），中文俗称**七日斑**、**蚕面**，老一辈人称患病为**起棂**。这是一种病因不明的慢性皮肤病，主要特征是面部皮肤逐渐出现排列规则的网格状缺损。病名取自宾夕法尼亚州伯利恒的莫诺卡西溪，因为有记载的最早病例就出在溪边的摩拉维亚弟兄会聚居地。

## 名称

「格状麻风」最早见于1790年代一份费城医生用拉丁文写的病例报告。他觉得病损的排列很像格栅（cancelli），就拿它跟麻风类比。后来证明两种病并无关系，但这个学名一直沿用下来。

「七日斑」是19世纪末传教士医生把这种病介绍到中文时用的名字。早期教会按照《利未记》第十三章的做法，把疑似患者单独关七天再看，这个名字就是从这里来的。「蚕面」和「起棂」都是民间说法，出处不详。「起棂」多用作动词，比如“他起棂了”，近年已经很少听到。

阿巴拉契亚山区的人把这种病叫作 **the Fretting**，词源是英王钦定本《利未记》里的 "fretting leprosy"。摩拉维亚弟兄会内部早年管它叫 **das Hölchen**（小洞），这个词后来被教会刻意弃用。2008年，美国疾病控制与预防中心的报告用了描述性名称「进行性窗孔性皮病」，缩写 **PFD**。

## 历史

1747年到1749年，赫恩哈格和伯利恒两地的弟兄会记录里，零星提到几名成员脸上出现了小孔状的病损。那几年正是弟兄会尊崇基督肋旁伤口的时期，有些信徒把这种病损看成恩典，而不是疾病。1749年以后，教会领导层叫停了这套敬拜方式，那段时期的档案大部分被销毁，所以现在能确认的18世纪病例不到十例。

19世纪，富兰克林州山区和德塞雷特各留下少量病例记录，大多出自乡村医生或巡回牧师之手，描述都很简略。国家冷库里保存着一张照片，拍的是两件病人头部标本被公开展示的场面。拍摄的时间、地点和展示方都没有登记，一般认为拍于1940年代。

2007年起，美国东部的病例明显增多。疾病控制与预防中心在2008年发表了第一份系统报告，推测这种病和接触纺织品有关，但没能分离出病原。

## 2009年的广播

2009年秩序崩溃前后，各地的应急广播陆续公布了几条识别特征。最先公布的是衣物上洗不掉的绿色或红色斑点，接着是耳后的细小凹坑，之后又提醒患者的伤口可能不出血。几天后，广播撤回了衣物斑点那一条，还要求居民不要焚烧患者的衣物，但没有说明原因。此后又有一条提示：如果发现家人长时间站在窗前，不要从背后靠近。一些地区录到的最后一次广播在念到下一条时中断了。

这些特征在健康人身上也很常见，比如痤疮留下的疤、脱水，还有长期没换洗的衣服。当时因此出现了大量误判。

## 临床表现

早期病损通常出现在耳后和指腹，是针尖大小的凹陷。几个月到几年里，凹陷会慢慢扩大、彼此连通，在面部形成大致呈六边形的网格。患者一般说疼得不厉害，病损处出血也很少。部分家属反映，患者常长时间站在窗前，但这和疾病本身有没有关系，至今没有定论。

这种病的传播途径、潜伏期和预后都不清楚，也没有公认有效的治疗方法。现有的晚期病例描述大多来自家属而不是医生，彼此差别很大。
