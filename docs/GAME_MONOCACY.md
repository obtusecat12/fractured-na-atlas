# 莫诺卡西病：约洛县（经营游戏）/ Monocacy: Yolo County (management game)

原型：`site/game/index.html`（直接用浏览器打开，沿用地图站的 2009 谷歌地图外壳、`style.css`、`sprites.css`、`7s.css`、`lang.js`、`cursors.js`）。

## 基调（2026-11-21 用户定）
正常的政治灾难剧，不写恐怖片，也不写成孤立无援。日常生活照常进行，对外是通的（谈判、贸易、和邻县分担），难民就是普通人口，莫诺卡西病就是一种传染病，灵异只作为谣言出现。

## 核心
- 玩家是约洛县（西萨克拉门托，隔河是州议会大厦）。
- 压力来自州层的内斗：州长办公室、加州应急委员会（1970 年依法设立）、Cal EMA（2009-01-01 成立）。三方通过广播、公文、拨款和联络官来拉拢或施压各县。
- 借鉴冰汽时代：广播代替降温（新的病例标准会先预告），县应急指挥中心代替发电机，县紧急条例代替法律书，用信任/恐慌和承诺系统，外勤队负责探索迷雾，后期难民潮加最后一次广播代替风暴。
- 地图：区域、县、城镇三层；开局就能看到邻近政权，放大后能看到它们大部分现状；远处的地区是 2009 谷歌地图那种「没有影像」的灰格。
- 建造：用谁的钱建，建筑就挂谁的牌子。

## 原型已有
- 顶栏：日期、时间、速度、下一天；信任和恐慌；三方好感度。
- 侧栏标签：概况（统计、承诺、广播、城镇）、周边（邻近政权、迷雾地区、外勤队）、条例（可签署，互斥）、建造（资金、分类、选出资方、在地图上放置）、公文（Gmail 2009 风格，可执行、搁置、回复）。
- 地图：三种模式（地图、立场、病例）；图层开关；点击城镇、设施、邻县会弹出信息气泡；在建的设施显示「施工中 · 待影像更新」。
- 事件：7.css 对话框（例如周五橄榄球赛）。
- 中英切换（齿轮菜单），默认中文。

## 待定
